# 工单 #2：平台登录与模型 API 配置

## 实现范围

已接入登录页面、服务端页面保护、受保护的配置接口、退出登录及单一 Models 配置表单。此工单不运行 Strix、不连接任务系统，也不改变其他页面的演示能力。

根页面改为服务端检查会话，原界面迁至客户端组件；Models 的六项模拟数据被单一配置表单替换，侧栏不再显示固定模型数量。原有其他模块保持。

## 技术选择

- 采用适合本机单用户PoC的单管理员模式，无注册、外部身份服务、角色或多租户管理。
- 初始化命令创建随机密码或使用用户提供的密码，存储随机盐与 scrypt 摘要，重复初始化拒绝覆盖。
- 浏览器使用 HttpOnly、SameSite=Lax、12小时 cookie。cookie 保存随机令牌，服务端以令牌摘要索引持久会话；退出删除服务端会话，旧 cookie 随即失效。HTTP 本机开发下不设置 Secure，直接HTTPS请求设置 Secure；反向代理和公网部署不属于本次验证范围。
- 每个受保护接口检查会话；写接口检查浏览器 Origin 与请求 Host，不仅依赖页面重定向。
- 数据保存在私有本地目录，文件权限0600、目录0700。配置原子替换；API Key 使用 AES-256-GCM 加密，密钥单独保存为 master.key。它保护磁盘文件中的明文，不抵御同时取得全部目录及系统权限的攻击者。
- 采用文件记录，满足本机单管理员及单配置范围；未增加数据库或远程服务。数据结构包括账户、会话、模型配置。后续任务状态的存储选择仍由对应工单确定。
- 默认启动监听127.0.0.1。没有增加公网防护、暴力破解限流、MFA或SSO；本期不按公网生产身份系统交付。

## 模型接口约定

| 操作 | 公开接口 | 说明 |
|---|---|---|
| 登录 | POST /api/auth/login | username、password；成功设置会话cookie |
| 会话查询 | GET /api/auth/session | 返回已登录用户名；未登录401 |
| 退出 | POST /api/auth/logout | 删除会话，清除cookie |
| 配置读取 | GET /api/model-config | 返回baseUrl、model、hasApiKey、configured、updatedAt，无密钥 |
| 配置保存 | PUT /api/model-config | baseUrl、model、可选apiKey和clearApiKey |
| 测试连接 | POST /api/model-config/test | 检查当前填写配置，不自动保存 |

配置入口支持 OpenAI Chat Completions 兼容协议，将基础地址与 `/chat/completions` 组合，发送模型标识和一条小型问答请求。当前不支持原生Anthropic、Azure专有鉴权或Responses专用接口，需经兼容网关或后续适配。连接成功只证明该次问答返回有效内容，不证明Strix工具调用兼容。

已有密钥不回传。相同接口地址留空密钥表示保留；可明确勾选清除。更换基础地址后不自动将旧密钥发送到新地址，需重新填写。参考资料和任务字段不在本工单实现。

错误包括未登录401、非法输入400、跨站写入403、模型鉴权错误、模型名称/接口错误、限流、无效响应、连接失败及超时。模型侧401/403映射为本地422，防止页面把模型鉴权错误误认作平台退出。只返回标准化说明，不回显模型服务原始错误或响应正文。

整体连接测试15秒超时，覆盖响应头与正文。API基础地址允许本机或内网HTTP/HTTPS地址；拒绝用户信息、查询参数和URL片段。密钥保存在单独字段。

## 运行与测试

初始化、启动及构建命令见根README。账户和配置在服务重启后保留；应用不需要每次启动重新初始化。恢复数据时须同时恢复master.key。

`npm run test:api`：真实Next HTTP接口测试，覆盖访问保护、初始化登录退出、密钥隐藏、配置保存、模型HTTP请求及错误、清除/保留密钥、服务重启与超时。

`npm run test:ui`：Playwright驱动真实Chrome，操作登录表单、Models表单、保存、测试连接、错误反馈、刷新、服务重启及退出；保存一张不含密钥的页面截图。

测试中的模型服务是独立的本地HTTP夹具，用于验证服务端确实发送请求以及错误处理，不是实际LLM推理验收。没有提供客户模型凭据，本轮不宣称已完成客户模型联通或Strix执行。

类型检查、ESLint及生产构建单独运行。现有组件库的ESLint警告与本工单结果分别记录；npm审计告警不自动执行强制升级。
